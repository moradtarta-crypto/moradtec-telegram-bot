# MoradTec Telegram Assistant

بوت Telegram لإدارة منشورات قناة **@MoradTecAI** مع نشر تلقائي لمحتوى المالك بعد إرساله عبر أمر `/post`.

## المزايا الحالية

- استقبال أوامر المالك فقط بعد ضبط `OWNER_ID`.
- إعداد منشور نصي أو صورة مع تعليق باستخدام `/post`.
- إنشاء مسودات عربية تقنية أكثر تخصصاً باستخدام `/draft الموضوع` دون نشرها تلقائياً.
- محاولة توليد صورة مخصصة بالذكاء الاصطناعي عبر Cloudflare Workers AI عند ضبط بيانات API، ثم الرجوع إلى Wikimedia Commons عند تعذر التوليد؛ صور Commons تُرسل مع المصدر ومعلومات الترخيص.
- اقتراح أفكار محتوى تقنية جاهزة للتطوير باستخدام `/ideas` (أمر للمالك فقط).
- البحث عن أدوات ومواقع الذكاء الاصطناعي حسب المهمة باستخدام `/tools المجال`، وفحص صفحاتها الرسمية ثم إنشاء شرح عربي لطريقة الاستخدام وروابط مباشرة للمواقع (أمر للمالك فقط).
- فحص ذاتي للسلامة والإعدادات وبنية الأوامر باستخدام `/selfcheck`، مع تحليل توصيات عبر Workers AI.
- إعداد خطة تحسين مرتبة حسب هدف المالك باستخدام `/improve الهدف`؛ هذه المرحلة للقراءة والتخطيط فقط ولا تعدّل الكود أو تنشره.
- إضافة حتى 4 أزرار روابط HTTPS داخل المنشور.
- النشر التلقائي لمحتوى المالك بعد إرساله باستخدام `/post`.
- إلغاء عملية إعداد المنشور باستخدام `/cancel` قبل إرسال المحتوى.
- لا توجد مفاتيح أو رموز سرية محفوظة في هذا المستودع.

## المتطلبات

- Python 3.10 أو أحدث.
- بوت أنشأته عبر BotFather.
- إضافة البوت إلى قناة @MoradTecAI ومنحه صلاحية **Post Messages**.

## متغيرات البيئة

اضبط هذه القيم في إعدادات خدمة الاستضافة كمتغيرات سرية/خاصة:

| المتغير | القيمة |
|---|---|
| `BOT_TOKEN` | رمز البوت من BotFather (لا تنشره أو ترسله في المحادثات) |
| `OWNER_ID` | رقم حساب Telegram الخاص بالمالك، ويُعرف عبر أمر `/id` |
| `CHANNEL_ID` | `@MoradTecAI` |
| `CLOUDFLARE_ACCOUNT_ID` | اختياري: معرّف حساب Cloudflare لتوليد الصور؛ أضفه في إعدادات الاستضافة فقط ولا تحفظه في GitHub |
| `CLOUDFLARE_API_TOKEN` | اختياري: رمز API بصلاحية Workers AI: Edit؛ أضفه في إعدادات الاستضافة فقط ولا تحفظه في GitHub |

## التشغيل

```bash
pip install -r requirements.txt
python bot.py
```

## الاستخدام

1. افتح البوت وأرسل `/id` لمعرفة معرّف حسابك.
2. استخدم `/ideas` للحصول على أفكار محتوى تقنية، أو `/tools إنشاء فيديو بالذكاء الاصطناعي` للبحث عن أدوات مناسبة وقراءة شرح عربي وروابطها الرسمية. ثم استخدم `/draft موضوع المنشور` لإنشاء مسودة قابلة للتعديل؛ لا تُنشر المسودة تلقائياً.
3. لنشر محتوى بنفسك، أرسل `/post` ثم أرسل النص أو الصورة مع تعليق؛ سيتم النشر مباشرة في القناة.
4. لإضافة زر رابط، أضف سطراً مستقلاً بهذا الشكل:

   `زر: افتح الموقع | https://example.com`

5. يمكنك إضافة حتى 4 أزرار، ويجب أن تكون الروابط بصيغة HTTPS.

> الأمر `/draft` يحاول أولاً إنشاء صورة عبر نموذج `@cf/black-forest-labs/flux-1-schnell` في Cloudflare Workers AI عند ضبط `CLOUDFLARE_ACCOUNT_ID` و`CLOUDFLARE_API_TOKEN`، ثم يبحث في Wikimedia Commons كخيار احتياطي. توفر الخطة المجانية حصة يومية قدرها 10,000 Neurons؛ عند استنفادها تتوقف الطلبات المجانية حتى إعادة الضبط، ولا تُفرض رسوم تلقائياً على الخطة المجانية. إذا لم تضف بيانات Cloudflare أو تعذر التوليد، ينتقل البوت تلقائياً إلى Commons. راجع الصورة ومصدرها ومحتوى المسودة قبل النشر. الأمر `/ideas` يقدم أفكاراً تحريرية عامة ولا يجلب الأخبار الحية. لا تضف أي رمز أو مفتاح سري إلى GitHub مطلقاً.


## البحث عن أدوات الذكاء الاصطناعي

- الأمر `/tools مجال أو مهمة` يبحث في الويب عن مواقع أدوات الذكاء الاصطناعي، ويفحص صفحات النتائج قبل عرضها.
- يطلب من نموذج Cloudflare Workers AI كتابة شرح عربي مستند إلى نص الصفحة الرسمية، مع طريقة البدء ومثال عملي. لا يخمّن الأسعار أو الميزات غير الموجودة في المصدر.
- يعرض رابط الموقع الرسمي وزر فتح مباشر. إذا تعذر التحقق أو التلخيص، يصرّح بذلك بدلاً من اختلاق خطوات.
- يعتمد البحث على نتائج DuckDuckGo HTML، ولذلك قد تختلف النتائج أو يتعذر البحث مؤقتاً إذا تغيرت صفحة البحث أو حظرت الطلبات.
- يتطلب `CLOUDFLARE_ACCOUNT_ID` و`CLOUDFLARE_API_TOKEN` الموجودين أصلاً لتوليد الصور. استدعاءات نموذج النص تستخدم حصة Workers AI المتاحة في حساب Cloudflare.


## النواة الأولية للتطوير الذاتي الآمن

- `/selfcheck` يجري فحوصات محلية ثابتة لصحة صياغة Python، وتسجيل الأوامر، وحماية المالك، وسرية Webhook، ومتغيرات التشغيل، ووجود ملف المتطلبات.
- `/improve الهدف` يرسل نتائج الفحص والهدف إلى Workers AI للحصول على خطة تحسين عربية مرتبة.
- لا تُرسل قيم الأسرار إلى النموذج، ولا تُنفّذ الشيفرة التي يولدها النموذج، ولا تُعدّل هذه الأوامر ملفات المشروع.
- توجد اختبارات وحدات وفحوصات GitHub Actions للتحقق من الصياغة والاختبارات عند فتح Pull Request أو دفع تحديث.
- مرحلة لاحقة يمكنها إعداد تغييرات برمجية في فرع مستقل وفتح Pull Request بعد إضافة GitHub Fine-grained token بصلاحيات محدودة؛ تبقى مراجعة التغييرات ودمجها منفصلين عن التشغيل الحي.
